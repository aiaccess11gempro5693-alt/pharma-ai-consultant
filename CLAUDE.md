# AI-консультант по продукту для фармы и БАД

Чат-консультант по продукту фармкомпании или бренда БАД, который отвечает только согласованными формулировками («атомами»). Одна база знаний обслуживает четыре аудитории: покупатель, фармацевт, врач, медицинский представитель.

Команда: Владимир (ЦентрФарма), Олег (прогоны на своей модели, стейкхолдер).
Статус: этап обсуждения концепции, до разработки. Блоки А–Д приняты, организационные вопросы сейчас не обсуждаем.

Перед работой прочитай: `docs/discussion/decisions.md` (что решено), `docs/discussion/open-questions.md` (что открыто), `docs/discussion/plan.md` (план из созвона), `docs/discussion/product-notes-statinoris.md` (факты и расхождения по продукту).

## Ключевые принципы (из хендовера)

- Согласуем не ответы, а атомы. Атом — одно проверенное утверждение с ID, законченное предложение, цифры и дозы буквально по источнику.
- Бот не может сказать ничего нового: любой факт в ответе берётся из атома. Остальное — связки без фактов.
- Одна база, четыре голоса: аудитории — это теги на атомах, а не четыре бота.
- Последняя проверка — детерминированное правило, а не нейросеть. Непонятный вопрос → служебная фраза.
- Стартуем с линейки «Контроль» (ответ собирает скрипт), «Живой диалог» — апгрейд после пилота.

## Идея из созвона (обсуждается)

- Два слоя (принято 02.10): свободный слой рассказывает о бренде и компании через RAG по очищенному набору документов; при переходе на продукт или здоровье — только атомы, ответ собирает скрипт.
- Цветовая разметка атомов по риску: зелёный / жёлтый / оранжевый / красный.
- Конвейер: источники → генерация вопросов по ролям и каналам (~1000) → атомы (~300–400 на продукт) → прогоны → дозаведение.
- Итог: мини-платформа — личный кабинет производителя, много ботов в разных каналах (сайт, Telegram, MAX, VK), журнал диалогов, аналитика, фиксация жалоб.

## Пилотный продукт

Статинориз (Консумед / изготовитель ТАУРУС), БАД, фиторегулятор липидного обмена. Материалов от клиента пока нет — собираем из открытых официальных источников (РЛС, Видаль, сайт бренда).
В пилоте обе формы — таблетки 900 мг и капсулы 650 мг, с явной разметкой различий. Статинориз Форте — продукт для проверки дельты.

## Структура репозитория

- `docs/sources/` — исходные файлы (хендовер, презентация, расшифровка созвона) и их markdown-версии
- `docs/discussion/` — план обсуждения, решения, открытые вопросы
- `products/<продукт>/sources/` — собранные материалы по продукту
- `products/<продукт>/atoms/` — база атомов
- `products/<продукт>/questions/` — тестовые вопросы
- `brand/` — стилевой слой, служебные ответы, стоп-лист

## Правила работы

- Язык документации и атомов — русский.
- Не добавлять в атомы ничего, чего нет в источнике. Неоднозначное помечать «на проверку».
- Лечебные формулировки («лечит», «гарантирует», «безопасно», «лучше, чем», сравнения с конкурентами) — только в красную зону, не в ответы.
- Решения по концепции фиксировать в `docs/discussion/decisions.md` с датой.

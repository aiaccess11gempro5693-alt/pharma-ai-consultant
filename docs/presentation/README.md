# Презентация: AI-консультант по продукту

11 слайдов: проблема, принцип атомов, решения А–Д, цветовая разметка, логика бота, правила безопасности, примеры на Статинорисе, 849 вопросов, каналы, вопросы к Олегу и следующие шаги.

- `presentation.pdf` — для просмотра и отправки.
- `presentation.html` — то же в браузере, с заметками докладчика под слайдами.
- `source/` — исходники слайдов (редактируемая версия живёт в артефакте claude.ai).

В PDF и HTML без интернета шрифты заменяются системными; точный вид — в артефакте.

# Открытые вопросы — AI-консультант по продукту

Кто решает: **мы** — внутри команды, **Олег** — нужен его ответ, **клиент** — выясняем у клиента.

## А. Концепция

Принятые правила: основа — атомы; база знаний — только атомы, RAG по сырым документам не используем; маршрутизация по теме, при сомнении — атомный режим, жалобы проверяются первыми; свободный слой без фактов.

- [ ] Олег согласен, что свободный слой не утверждает фактов, а «идеология» бренда — это атомы уровня «бренд»? Или он видит для свободного слоя другую задачу? — **Олег**
- [ ] Кто у клиента получает жалобы на самочувствие и в какой срок? — **клиент**
- [ ] Как проверяем, что собеседник — врач или медпред (закрытый канал, код, авторизация)? — **мы + клиент**
- [ ] Что отвечаем, когда пользователь присылает свои анализы или цифры? — **мы, согласует клиент**
- [ ] Когда бот предлагает связаться с живым человеком (горячая линия)? — **мы + клиент**
- [ ] Кто отвечает, если согласованный атом оказался неверным или устарел? Фиксируем в договоре пилота — **Олег + клиент**

## Б. Атомы и формулировки

Принятые правила: систему проектируем под продукты до ~1000 атомов (включая лекарства); один факт — один атом, варианты по аудиториям только где нужно; текст атома не меняется, гибкость в связках; цвет = уровень риска; юристы видят все атомы, зелёные подтверждают списком.

- [ ] Реальное число атомов на БАД (Статинорис) — меряем на прогонах — **мы + Олег**
- [ ] Какая доля атомов переходит между продуктами? Меряем на Статинорис → Статинорис Форте — **мы**
- [ ] Как склеиваем атомы без правки текста внутри атома — **мы**
- [ ] Финальные критерии цветовой разметки — **мы, показываем клиенту**
- [ ] Зелёные атомы: юристы подтверждают списком или не смотрят вовсе? — **клиент**
- [ ] Какую форму Статинориса берём в пилот: таблетки 900 мг или капсулы 650 мг? — **клиент / Олег**

## В. Модель

Принятые правила: классификатор двухшаговый (эмбеддинги → лёгкая модель); уверенность по косвенным признакам; отдельный фильтр жалоб; код не привязан к модели; порог настраиваем на модели-кандидате для прода.

- [ ] Какая лёгкая модель для классификатора и какая модель эмбеддингов? — **мы + Олег**
- [ ] Российская модель и хранение данных в РФ обязательны (152-ФЗ, данные о здоровье)? — **клиент**
- [ ] Если РФ обязательна: GigaChat / YandexGPT или открытая модель в российском облаке? — **мы + клиент**
- [ ] Прогоны: генерация — на токенах Олега; настройка порога — на какой модели-кандидате? — **Олег**

# Каналы для ботов

Олег в созвоне просил посмотреть, куда можно ставить ботов («сайт, телеграм, макс… ВКонтакте… ну, вообще, посмотри»). Собрано 30.09.2026 по открытым публикациям. На устройство бота выбор канала не влияет (решение Д2): ядро одно, канал — только способ доставки.

## Сводка

| Канал | Техническая возможность | Риски в РФ | Оценка |
|---|---|---|---|
| **Виджет на сайте** | Полностью наш код, встраивается на любую страницу (сайт бренда, аптека, курс) | Нет | Базовый канал, подходит для пилота |
| **MAX** | Есть Bot API для чат-ботов и мини-приложений; доступ через верификацию юрлица и @MasterBot | Нет, национальный мессенджер | Перспективный, но нужна верификация юрлица клиента |
| **VK (сообщество бренда)** | Боты сообществ через Bots Long Poll API или Callback API, давно и стабильно | Нет | Рабочий, если у бренда есть сообщество |
| **Telegram** | Bot API, самый простой в разработке | С февраля 2026 РКН замедляет Telegram; звучали оценки о полной блокировке к сентябрю 2026 | Высокий риск, не закладывать как основной |
| **WhatsApp** | WhatsApp Business API | Заблокирован в РФ с 11.02.2026; Meta признана экстремистской | Исключаем |
| **Ozon, Wildberries** | Вопросы покупателей доступны через API продавца; у WB ИИ-ответы на вопросы — только черновик, публикует человек | Нет | Хорошо ложится на хендовер: бот готовит черновик, менеджер подтверждает |
| **Курсы (ЦентрФарма)** | Тот же виджет на странице курса, с известным продуктом и аудиторией | Нет | После пилота (решение Д3) |

## Что важно для фармы и БАД

- **Закон 41-ФЗ (с 01.06.2025)** запрещает части организаций общаться с клиентами через иностранные мессенджеры (Telegram, WhatsApp и др.): госструктурам, компаниям с госучастием, банкам, маркетплейсам, сайтам объявлений, операторам связи. Производителей БАД в перечислениях публикаций нет, но это нужно подтвердить у юристов клиента.
- **Telegram** остаётся самым простым для разработки, но его судьба в РФ неясна. Если клиент захочет Telegram, стоит сразу держать MAX как замену: ядро то же, меняется только модуль канала.
- **Маркетплейсы** — единственный канал, где вопросы о продукте уже задают без нашего участия. Режим «бот пишет черновик — человек публикует» совпадает с логикой «Контроля» и снимает часть рисков.

## Открытые вопросы

- Подпадает ли клиент под 41-ФЗ (есть ли госучастие)? — **клиент**
- Есть ли у бренда сообщество VK, канал в MAX, магазины на Ozon и WB? — **Олег / клиент**
- Ozon: какие именно методы API для вопросов покупателей доступны продавцу — проверить в документации Ozon Seller API при реализации — **мы**

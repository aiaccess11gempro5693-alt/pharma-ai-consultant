# Вопросы по Статинорису

`meanings.csv` — список вопросов **по смыслу** (решение Г1): один смысл — одна строка, без перефразировок. Первая партия, 196 смыслов. Ориентир — около 1000; дальше дополняем, пока новые партии дают новые смыслы.

## Поля

- **id** — П (покупатель), Ф (фармацевт), В (врач), М (медпред) + номер.
- **канал** — «все», если смысл возникает в любом канале; иначе канал, где он специфичен (сайт, мессенджер, маркетплейс, канал для специалистов, инструмент медпреда).
- **тема** — раздел, к которому относится вопрос.
- **тип** — «обычный» или «ловушка» (беременность, дети, статины, удвоение дозы, лечебные обещания, сравнения, жалобы, анализы).
- **ожидаемый ответ** — черновик разметки (решение Г3):
  - `А:<раздел>` — ответ из атомов этого раздела;
  - `К` — красная зона: утверждение об эффекте или взаимодействии, бот сам не отвечает, пока нет согласованного атома;
  - `С:<вид>` — служебная фраза: `врач`, `жалоба`, `анализы`, `сравнение`, `вне темы`, `где купить`, `горячая линия`, `сервис площадки` и др.;
  - `?` — в источниках нет данных или они расходятся, на проверку.

## Следующие шаги

1. Проверить список смыслов и дополнить.
2. На каждый смысл — 3–5 формулировок (коротко, разговорно, с опечаткой, в составном вопросе) для тестовых наборов.
3. Разделить формулировки на три набора: настройка, отложенный, ловушки.
